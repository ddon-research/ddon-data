# Packet pattern includes, client 03040008

The shared files of `packets/patterns/03040008/include/`, for a reader of a pattern who wants to know where a type lives and which patterns use it. Every pattern starts with `#pragma endian big` and includes what it needs from that directory. A label in a code span names a report: [the key](packet-ids.md#report-labels). After a change to an include, re-export every pattern that includes it, as [Export packets to JSON](../how-to/export-packets-to-json.md) says.
