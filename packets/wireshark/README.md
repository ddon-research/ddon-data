# Wireshark helpers

A Lua postdissector for DDON's TCP framing (`wireshark-ddon-tcp-postdissector.lua`) and display filters for the first packet of each stream kind (`wireshark-filters.txt`), hand-authored. Neither names a client build, and the dissector does not decrypt. [Inspect captures in Wireshark](../../docs/how-to/inspect-captures-in-wireshark.md) says how to install and read them.
