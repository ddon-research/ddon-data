# Packet patterns, client 03040008

ImHex patterns for the decrypted packets of the PC client 03040008 (Season 3) in `packets/decrypted_raw/`, one `<packet name>-pattern.cpp` per packet, with shared types in `include/`. They are hand-authored from the PC code, and [`packets/imhex-export.sh`](../../imhex-export.sh) exports them to `packets/decrypted_json/`.
