# Pharos OOAnalyzer

Docker wrapper for running [Pharos OOAnalyzer](https://github.com/cmu-sei/pharos) on large 32-bit Windows executables: `run.sh` starts `docker-compose.yml`, and `scripts/analyze.sh` runs the steps inside the container. Hand-authored. The steps, variables and failures are in [Run Pharos](../../docs/how-to/run-pharos.md).
