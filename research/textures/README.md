# Textures

Hand-authored helpers for the client's textures. The steps are in [Convert textures](../../docs/how-to/convert-textures.md).

| File | What it is |
| --- | --- |
| `convert-with-direcxtex.sh` | DDS to PNG through `texconv.exe`, with flags per file |
| `convert-with-magick.sh` | DDS to PNG through ImageMagick |
| `DirectDrawSurface-pattern.cpp` | ImHex pattern of the DDS format |
| `texture-research.md` | Research note: the `FORMAT_` and `TEXTURE_TYPE_` values found in the extractor's JSON, with the commands |
