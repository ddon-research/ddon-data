= DDON Data

Reverse-engineering data for Dragon's Dogma Online (DDON): extracted client resources, disassembler
exports, decrypted network traffic, client patches and the research built on them. It holds the
Season 3 PC client (build `03040008`) and the PS4 export (build `PS4_02020005`), versioned so results
can be compared across builds and cross-referenced.

All data is provided for research, interoperability and educational purposes.

== Top-level directories

[cols="1,3"]
|===
|Path |Holds

|`client/`
|client resources of build `03040008` as JSON, and their summaries

|`binaries/`
|IDA exports and static dumps of the PS4 ELF; the Android companion app's C#

|`packets/`
|captured traffic, decrypted and decoded; the patterns and engine that decode it

|`patches/`
|radare2 patch scripts for Windows `DDO.exe` builds; to use one: link:docs/how-to/apply-a-client-patch.md[Apply a client patch]

|`research/`
|resource patterns, notes and research projects

|`docs/`
|the documentation

|`tools/`
|the local gate and hooks

|`specs/`
|the planned features, with their evidence reports
|===

Coding agents start at `AGENTS.md`.

== Season repositories

Earlier seasons, their resource patterns among them, are separate:
https://github.com/ddon-research/ddon-data-s1[ddon-data-s1] (Season 1, client 01010004, patterns in
`ddon-data-s1/research/01020003/`, named after the build of its PS4 export, inferred) and
https://github.com/ddon-research/ddon-data-s2[ddon-data-s2] (Season 2, patterns in
`ddon-data-s2/research/02030004/`, with the unfinished DWARF-based recompilation output).
